# ليه الرياض؟

## 1. ما هو المشروع؟

موقع عربي عن مدينة الرياض، عنوان الصفحة الرئيسية: «ليه الرياض؟ - اكتشف جوهر العاصمة السعودية». الصفحة `index.php` تجمع أقسامًا عن المدينة، وتربط إلى صفحات فرعية، وتعرض تعليقات الزوار من MySQL. الاسم الإنجليزي في README السابق: Why Riyadh?

مجلد شقيق باسم `Leh AlRiyadh 2` يطابق هذا المجلد في أسماء الملفات. الفرق الوحيد الذي أظهره مقارنة تجزئة الملفات: `assets/images/Logo.png` (159917 بايت هنا، و 389442 بايت في المجلد الثاني).

## 2. لماذا يوجد هذا المشروع؟

README السابق يشرح أن الموقع يعرّف بالرياض كوجهة سياحية وثقافية ويعرض معالم ودليل زائر وفعاليات. الصفحة الحالية ما زالت تحمل هذا الاتجاه: أقسام عن الرياض، معالم، ثقافة، فعاليات، تسوق، ودليل. بعض ما ذكره README السابق (خريطة تفاعلية، قاموس نجد، زاوية تعليمية كأقسام `#map` و `#dictionary` و `#education`) غير موجود كمعرّفات أقسام في `index.php` الحالي.

## 4. ماذا يستطيع النظام أن يفعل؟

أقسام `index.php`:

| المعرّف | المحتوى المرتبط |
| --- | --- |
| `about` | روابط إلى `about/history` و `about/why-riyadh` و `about/development` |
| `tourist` | معالم تاريخية وحديثة وطبيعية |
| `culture` | مأكولات، أزياء، فنون |
| `events` | موسم الرياض، حفلات، أحداث رياضية |
| `shopping` | أسواق، مولات، مقاهٍ ومطاعم |
| `guide` | فنادق ومواصلات |
| `what-they-said` | قسم «ماذا قالوا» |
| `comments` | نموذج تعليق وعرض آخر التعليقات |
| `contact` | قسم اتصال |

صفحات فرعية موجودة:

- `about/history/index.html` و `about/why-riyadh/index.html` و `about/development/index.html`
- `tourist/historical-landmarks` و `modern-landmarks` و `natural-landmarks`
- `culture/cuisine` و `traditional-clothing` و `traditional-arts`
- `events/riyadh-season` و `musical-concerts` و `sports-events`
- `shopping/traditional-markets` و `modern-malls` و `cafes-restaurants`
- `guide/hotels-accommodations` و `transportation` و `support-services`

مجلد `specialties/` فيه `business.html` و `computer-science.html` و `education.html` و `engineering.html` و `law.html` و `medicine.html`. عنوان صفحة الطب: «الطب - التخصصات». هذه الصفحات غير مذكورة في روابط `index.php`.

التعليقات: `add_comment.php` يدرج في جدول `comments`، و `get_comments.php` يعرض آخر 50 تعليقًا.

## 5. كيف يعمل النظام؟

```
الزائر
  -> index.php (PHP يضم get_comments.php)
  -> صفحات HTML الفرعية والوسائط في assets
  -> عند التعليق: POST add_comment.php
  -> config.php
  -> MySQL قاعدة leh_alriyadh جدول comments
  -> إعادة توجيه إلى index.php#comments
```

فتح `index.html` كما في README السابق لا يطابق الملفات: الملف الرئيسي `index.php`، ولا يوجد `style.css` ولا `script.js` في الجذر. التنسيق والنص داخل الصفحات.

## 6. أمثلة واقعية

### إرسال تعليق

1. النموذج `commentForm` في `index.php` يرسل `POST` إلى `add_comment.php`.
2. الحقلان `name` و `message`.
3. إن فرغا يتم التوجيه إلى `index.php?error=empty_fields`.
4. الاسم الأطول من 255 أو الرسالة الأطول من 5000 يرفضان برمز `name_too_long` أو `message_too_long`.
5. النص يمر على `htmlspecialchars` ثم `INSERT` محضّر.
6. النجاح: `index.php?success=comment_added#comments`.
7. `get_comments.php` يعرض الاسم والتاريخ بصيغة `Y-m-d H:i` والنص.

### قراءة معلم

1. من قسم `tourist` يفتح الزائر مثل `tourist/historical-landmarks/index.html`.
2. الصفحة HTML ثابتة مع صور أو فيديو من `assets`.
3. لا يتغير سجل في القاعدة.

`database.sql` يدرج ثمانية تعليقات تجريبية بأسماء مثل محمد العتيبي وفاطمة السالم. هذه بيانات البذرة داخل الملف.

## 7. رحلة المستخدم

1. فتح `index.php` عبر خادم PHP. فتحه كملف فقط لا يشغّل تضمين التعليقات.
2. التنقل بين الأقسام والصفحات الفرعية.
3. كتابة تعليق في قسم `comments`.
4. الحفظ في MySQL.
5. العودة إلى قسم التعليقات وظهور الصف الجديد ضمن أحدث 50.

لا تسجيل دخول.

## 18. الواجهة

- الصفحة الرئيسية PHP واحدة طويلة فيها الأقسام التسعة.
- الصفحات الفرعية HTML لكل موضوع.
- الاتجاه عربي في الصفحات التي فُحص عنوانها، مثل التخصصات `lang="ar" dir="rtl"`.
- لا تطبيق صفحة واحدة.
- التعليقات تُرسم من PHP لا من جلب JSON.
- وسائط كبيرة محلية. الفيديو الذي يزيد على 100 ميجابايت يُذكر بالاسم فقط:
  - `assets/suq al-awwalin/فديو.MOV`
  - `assets/videos/المقابلات.MP4`
  - `assets/videos/Arts/السامري.mov`
- أيقونة تبويب غير موثقة كوسم `rel="icon"` في الملفات التي فُحصت.

## 19. الخادم

`config.php` ينشئ PDO:

- المضيف `localhost`
- القاعدة `leh_alriyadh`
- المستخدم `root`
- كلمة المرور فارغة في الملف
- `utf8mb4`
- وضع الخطأ Exception

`add_comment.php` يستعمل جملة محضّرة. `get_comments.php` استعلام قراءة بلا مدخلات مستخدم: `SELECT * FROM comments ORDER BY created_at DESC LIMIT 50`.

عند فشل الاتصال يوقف `config.php` التنفيذ بنص «خطأ في الاتصال بقاعدة البيانات» ثم رسالة الاستثناء.

## 20. مسار الطلب

```
المتصفح
  -> index.php

  -> PDO SELECT

إرسال النموذج
  -> POST add_comment.php
  -> تحقق الطول والفراغ
  -> INSERT
  -> Redirect index.php?success=comment_added#comments
```

## 30. التثبيت

1. PHP مع PDO MySQL، وMySQL، وخادم مثل Apache أو `php -S`.
2. نفّذ `database.sql` لإنشاء `leh_alriyadh` وجدول `comments` والبذرة.
3. طابق `config.php` مع مستخدم القاعدة على جهازك.
4. افتح `index.php` من عنوان الخادم.
5. README السابق يقترح فتح `index.html` أو `python -m http.server`. ذلك الخادم لا ينفّذ PHP، والتعليقات لن تُحفظ عبره.

## 31. دليل التطوير

- قسم في الرئيسية: أضف `section` في `index.php` واربط صفحة تحت مجلد جديد.
- تعليق: الحقول تمر عبر `add_comment.php`. لتغيير الحد عدّل شروط الطول هناك وعمود SQL إن لزم.
- جدول جديد: لا بنية ترحيل. أضف SQL وملف PHP.
- صلاحية: لا طبقة جاهزة.
- صفحات `specialties` مستقلة بتنسيق داخلي.

- التقنيات: PHP و HTML وتنسيق داخل الصفحات و MySQL.
- المعمارية: صفحة رئيسية ديناميكية وصفحات فرعية ثابتة.
- قاعدة البيانات: `leh_alriyadh.comments` فقط.
- لا API بصيغة JSON.
- أهم الملفات: `index.php`، `add_comment.php`، `get_comments.php`، `config.php`، `database.sql`.
- التطوير: لا تعتمد على README السابق لأسماء `index.html` و `script.js`. قارن مع المجلد الشقيق إن نسخت وسائط؛ الفرق الحالي الملف `assets/images/Logo.png`.
